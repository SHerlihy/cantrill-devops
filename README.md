# Infrastructure Deployments as of AWS DevOps Professional by Adrian Cantrill

Deployments of architectures using an Infrastucture as Code (IaC) methodology with Terraform.
The architectures deployed are specified in Adrain Cantrill's course [AWS Certified DevOps Engineer - Professional](https://learn.cantrill.io/p/aws-certified-devops-engineer-professional).

The prinicipal deployment is "continuation" where I evolved the architecture from a database and files system migration to a prototype server that can be used to rapidly re-iterate and redeploy application changes to a highly available load balanced architecture.

Order of Completion:
1. IAM
2. beanstalk
3. lambda
4. containers
5. 53
6. cloudwatch
7. athena
8. storage
9. cdn
10. continuation
